# SYNENT_TASK5

📌 Project Overview

The To-Do List Web App is a simple and interactive task management application built using HTML, CSS, and JavaScript. It allows users to add, complete, and delete tasks while storing data in the browser's localStorage, ensuring tasks remain available even after refreshing or reopening the page.

🚀 Features
Add new tasks
Mark tasks as completed
Delete tasks
Store tasks using localStorage
Tasks persist after page refresh
Clean and responsive user interface

🛠️ Technologies Used

HTML5
CSS3
JavaScript (ES6)
Browser Local Storage

📂 Project Structure

To-Do-List-Web-App/
│
├── index.html
├── style.css
├── script.js

⚙️ How to Run the Project

Download or clone the repository.
Open the project folder.
Double-click index.html or open it in any web browser.
Start managing your tasks.

🎯 Functionality

Enter a task in the input field and click Add.
Click on a task to mark it as completed.
Click the Delete button to remove a task.
All tasks are automatically saved in localStorage.

📸 Output

The application provides a simple task management interface where users can:

Create tasks
Track completed tasks
Remove unnecessary tasks
Access saved tasks even after refreshing the page
